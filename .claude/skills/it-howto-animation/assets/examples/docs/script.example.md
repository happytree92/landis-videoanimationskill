# Sign in on a computer with your phone's passkey
Series: Passwordless sign-in · Part 2 of 3 · Length: 1:17 (draft_v3) · Platform: Windows 11 (23H2+) computer + Android 14+ / iOS 17+ phone
Sources: learn.microsoft.com/entra/identity/authentication/how-to-sign-in-passkey-authenticator (updated 2026-07-06, checked 2026-10-01);
reference footage R1 (laptop), C3 (Android), I2 (iPhone).
Prerequisites: a passkey in Microsoft Authenticator (Part 1); Bluetooth and internet turned on for both the phone and the computer.
Desktop PCs without built-in Bluetooth need a USB Bluetooth adapter for QR (cross-device) passkey sign-in.
If the organization restricts Bluetooth, IT must allow passkey-only Bluetooth pairing.
